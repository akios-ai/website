AKIOS 1.x ran YAML workflows with built-in agents and model clients. AKIOS 1.x is no longer maintained and is not intended for production use. The [migration guide](/docs/migration-1x-to-2.html) shows how to wrap an existing agent with `akios run -- <command>` and what replaces each 1.x feature.
